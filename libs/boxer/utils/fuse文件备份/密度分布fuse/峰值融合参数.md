# 峰值融合参数

本文档整理 `utils/fuse_3d_boxes.py` strict 3D-IoU density peak extraction 使用的参数名称、含义和默认值。

## 已有参数

| 参数名 | 默认值 | 含义 |
| --- | --- | --- |
| `--input` | 必填 | 输入 3DBB CSV 文件路径，例如 `output/ca1m-data260511/boxer_3dbbs.csv`。 |
| `--output` | `None` | 输出 fused CSV 路径；不指定时默认在输入文件名后加 `_fused`。 |
| `--iou` | `0.3` | strict 3D IoU 阈值。只有 `IoU3D(candidate_mode, box_j) >= --iou` 的框才能进入该 `mode_core`。 |
| `--min_detections` | `4` | 一个 `mode_core` 至少需要包含多少个 3DBB 才输出 fused box。 |
| `--conf_threshold` | `0.55` | 原始 3DBB 的最低置信度；低于该值的检测框在融合前先过滤。 |
| `--nms` | 关闭 | 是否在峰值融合后启用 3D NMS 去掉重复 fused boxes。 |
| `--nms_iou` | `0.4` | post-fusion 3D NMS 的 IoU 阈值。IoU 大于该值的 fused boxes 视为重复候选。 |

## 新增峰值融合参数

| 参数名 | 默认值 | 含义 |
| --- | --- | --- |
| `--mode_relative_density` | `0.4` | 候选 mode 的密度至少要达到当前初始簇最高密度的比例。用于防止边缘稀疏框在主峰被占用后形成错误 fused box。 |
| `--mode_kernel_power` | `1.0` | 截断 IoU kernel 的幂指数。值越大，越强调高 IoU 核心框，越压低边缘框权重。 |
| `--mode_min_conf_mass` | `3.0` | 一个 `mode_core` 的最低置信度总量；低于该值的候选峰值核心不会输出 fused box。 |

## 密度计算

对初始簇中的每个候选框 `box_i`，使用 strict 3D IoU 计算密度：

```text
K(iou) = 0, if iou < --iou
K(iou) = ((iou - --iou) / (1 - --iou)) ** mode_kernel_power, if iou >= --iou

density_i = sum_j K(IoU3D(box_i, box_j)) * confidence_j
```

其中：

| 名称 | 含义 |
| --- | --- |
| `mode` | 一个密度峰候选框，通常是初始簇中的某个真实 3DBB。 |
| `mode_core` | 与该 `mode` 满足 strict IoU 阈值的一组核心框。 |
| `density_i` | 候选框 `box_i` 的密度分数，表示它周围有多少高置信、高 IoU 支持框。 |
| `confidence_mass` | `mode_core` 中所有框的置信度总和。 |
| `support_count` | `mode_core` 中框的数量。 |

## 硬规则

- 每个 3DBB 最多只能进入一个 `mode_core`。
- `mode_core` 只从尚未使用的框中选取。
- 被接受进某个 `mode_core` 的框会立即标记为 used，不能再进入后续 `mode_core`。
- 不使用弱兼容规则；距离远、IoU 不达标的偏移框不会参与融合。
- 低密度边缘框如果无法形成合格 `mode_core`，直接丢弃，不单独融合成框。
- 同帧不同框不互相支持，保留 cannot-link 约束。

## Mode 接受条件

候选 `mode_core` 需要同时满足：

```text
support_count >= --min_detections
confidence_mass >= --mode_min_conf_mass
density >= --mode_relative_density * best_density_in_initial_cluster
```

默认情况下：

```text
support_count >= 4
confidence_mass >= 3.0
density >= 0.4 * 当前初始簇最高 density
```

## 推荐命令

默认严格峰值融合：

```bash
python -m utils.fuse_3d_boxes --input output/ca1m-data260511/boxer_3dbbs.csv --iou 0.3 --min_detections 4 --mode_relative_density 0.4 --mode_kernel_power 1.0 --mode_min_conf_mass 3.0 --nms
```

推荐同时开启 post-fusion NMS 减少重复框：

```bash
python -m utils.fuse_3d_boxes ^
  --input output/ca1m-data260511/boxer_3dbbs.csv ^
  --iou 0.3 ^
  --min_detections 4 ^
  --conf_threshold 0.55 ^
  --mode_relative_density 0.4 ^
  --mode_kernel_power 1.0 ^
  --mode_min_conf_mass 3.0 ^
  --nms ^
  --nms_iou 0.4
```

## 调参建议

如果偏移框仍然影响中心点：

```text
--iou 提高到 0.35
--mode_kernel_power 提高到 2.0
--mode_relative_density 提高到 0.5
```

如果 fused boxes 变多：

```text
--iou 降低到 0.25
--mode_relative_density 降低到 0.3
开启 --nms，并使用 --nms_iou 0.4
```

如果真实物体漏掉：

```text
--min_detections 降低到 3
--mode_min_conf_mass 设置为 1.8
```

如果相邻物体被误合：

```text
--iou 提高到 0.35 或 0.4
--nms_iou 提高到 0.5 或 0.6，避免 post-fusion NMS 过度合并相邻物体
```
